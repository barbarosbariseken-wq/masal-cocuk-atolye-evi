# Masal Çocuk Atölye Evi — Web Sitesi

Bornova, İzmir'deki Masal Çocuk Atölye Evi'nin web sitesi.

## Dosyalar
- `index.html` — ana sayfa
- `randevu.html` — online randevu sayfası (talepler şimdilik WhatsApp'a iletilir)
- `assets/img/` — fotoğraflar
- `assets/video/` — videolar
- `favicon.svg` — logo / sekme simgesi

## Sık yapılan değişiklikler
- **Seans ücreti, süreleri, saatler, tatil günleri:** `randevu.html` içindeki `Ayarlar` bölümü.
- **Etkinlik takvimi:** `index.html` içinde `<!-- ETKİNLİKLER -->` bölümü.
- **Yeni fotoğraf:** `assets/img/` klasörüne ekleyip ilgili `<img src="...">` yolunu güncelleyin.

## Yayın
`main` dalına gönderilen her değişiklik GitHub Pages ile birkaç dakika içinde yayına girer.
